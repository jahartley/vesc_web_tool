# Simple Browser based VESC Tool
My vesc fork has gone well beyond the parameters of normal vesc, but also does not need all the extra apps and other things that come with vesc tool. This project will be to make a simple local html based web -> usb serial interface to be able to use the vesc terminal and and to receive, decode, log and graph telemetry that I have added specific to my application.

## Link
[Web Telemetry tool](https://jahartley.github.io/vesc_web_tool/wrsm.html)

## Sample Data
My first bench test sample data can be downloaded from my VESC [WRSM fork documentation folder](https://github.com/jahartley/bldc/tree/feature/wrsm/documentation). The WRSM_Diagnostic_Log_2026-08-21T06-46-42-263Z.csv style file names are uploadable to the github hosted tool (link above) and start analysis can be run.
